# 📊 Gráficos e Dashboards

Projetos de visualização de dados criados com Power BI e Python.

## 📁 Projetos

| Projeto | Ferramenta | Descrição |
|---------|------------|-----------|
| Zoológico | Power BI | Gráfico de barras com peso e idade dos animais |
| Titanic | Python (pandas) | Gráfico de pizza com sobreviventes por sexo |
| Vendas Mensais | Python (Matplotlib) | Gráfico de linha com evolução de vendas |

## 🛠️ Tecnologias

- Power BI
- Python (Pandas)
- CSV / Excel
- Git e GitHub

## 🚀 Como usar

1. Para arquivos `.pbix`, abra no Power BI Desktop
2. Para arquivos `.py`, execute com Python: `python grafico.py`
